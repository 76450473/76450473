《奇美拉纪元》GPT 端：用 ChatGPT 生产美术资产的使用说明
======================================================

这份说明教你：用你的 ChatGPT 订阅（不用 API，不额外花钱）把 88 张美术图做完，再打包交给 Claude。
每张图 ChatGPT 都会自己检查一遍，你也看一眼，两边都通过才算数。你只要回一个数字或一句话。

给 GPT 的这一份有三个文件：
  GPT项目指令.txt          → 粘贴到 ChatGPT 项目的"指令"里（相当于 skill）
  美术资产清单与提示词.txt → 上传到项目文件里（88 项的文件名、比例、背景、英文提示词）
  GPT使用说明.txt          → 本文件，给你看的


一、先说结论
------------
1. 用 ChatGPT 网页版（电脑上用 Edge 或 Chrome 打开 chatgpt.com），在里面建一个"项目（Project）"。
   电脑版 ChatGPT 客户端也有项目功能，用它也行；本说明按网页版写。
2. 项目里的"指令"加上"项目文件"，作用就等于 skill 加提示词：
   - 指令：粘贴《GPT项目指令.txt》的全部内容
   - 文件：上传《美术资产清单与提示词.txt》
3. 不用"自定义 GPT"：项目更简单；而且据 OpenAI 9 月的公告，自定义 GPT 会在 2026 年 12 月停用。
4. 不用上传 skill：ChatGPT 的"技能（Skills）"目前只开放给企业、教育等团队版，Plus 还用不了。
   项目指令就起 skill 的作用，效果一样。
5. 为什么不用 Codex：
   Codex 现在也能用订阅出图，不走 API；但它是给程序员用的软件，要安装、选文件夹、处理权限提示，
   而且它的出图功能目前常出小毛病（图没存下来、提前提示额度用完）。网页版看图、改图最直观，最简单。


二、准备（只做一次）
--------------------
1. 在电脑上新建一个英文名的空文件夹，例如 D:\art_pack（名字不要用中文；没有 D 盘就建在 C 盘或桌面）。
2. 让 Windows 显示文件扩展名：
   - Win11：打开任意文件夹 →「查看」→「显示」→ 勾选「文件扩展名」
   - Win10：打开任意文件夹 →「查看」→ 勾选「文件扩展名」
3. 让浏览器每次下载都问你"存到哪、叫什么名"（这样下载时就能顺手改好名字）：
   - Chrome：右上角 ⋮ →「设置」→「下载内容」→ 打开「下载前询问每个文件的保存位置」
   - Edge：右上角 … →「设置」→「下载」→ 打开「询问我如何处理每个下载」，下载时选「另存为」
   （不同版本的名字可能略有不同，意思一样就行。）
4. 在 art_pack 里先建好 credits.txt：右键 →「新建」→「文本文档」，改名为 credits.txt，
   用记事本打开，写一行：ChatGPT 图像生成（Plus 订阅）
   点「另存为」，编码选 UTF-8，保存。这样以后每次打包都会带上它。


三、建项目（只做一次）
----------------------
1. 打开 chatgpt.com 并登录。
2. 左侧栏找到「项目」→「新项目」，名字写：奇美拉美术。
3. 进入项目 → 点项目名旁边的「⋯」或「设置」→「指令」：
   打开《GPT项目指令.txt》，Ctrl+A 全选，Ctrl+C 复制，粘贴进去，保存。
   （指令上限 8000 字，这份大约 4800 字，放得下。）
4. 在项目页点「添加文件」，上传《美术资产清单与提示词.txt》。
5. 模型选名字里带「思考」或「Thinking」的那个。它能先检查自己画的图。
   如果提示思考额度用完了，换普通模型也能继续，只是自检弱一点，你自己多看一眼就行。


四、开始出图
------------
1. 在项目里点「新对话」，发两个字：
       开始
2. GPT 会问要不要先出一张"风格参考图"。回：要
   出图后满意就下载（文件名 style_ref.png），回 1。
   （这张图只用来定画风，不放进资产包。下载存到 art_pack 外面，例如 D:\style_ref.png，
    以后开新对话做角色或部件时要上传它来对齐画风。）
3. 接着它会做"定调批"7 张：人族女侠、虫族女主、虫族反派、复眼面罩、毒液吊坠、毒图标、腐沼背景。
4. 这 7 张都满意后，它会问"风格确认了吗？"，同时给一行"定调"接力码（复制到记事本存好）。回：确认
   之后它会按清单从第 1 项做到第 88 项，已经做过的会自动跳过。


五、怎么审图（最重要，记住这几个回复就行）
----------------------------------------
每一张图大概长这样：

    上一张【12】part_plating.png：自检 ✅ 单个束胸、纯白底     ← GPT 对上一张的检查
    【14/88】仪式肩带（人族部件）　1:1｜白底                    ← 这一张是什么
    ┌───────────────┐
    │ part_sash.png │  ← 这一张的文件名，小框右上角有「复制」按钮
    └───────────────┘
    （图片）
    自检 ✅ 单条肩带、朝右、纯白底        ← 这两行可能有，也可能没有
    回复：1=通过　2=重画　或直接写修改意见

ChatGPT 出完图经常不让它再说话，所以图下面没有"自检"很正常：
它会在你回复之后，在下一条的开头补上（就是上面第一行"上一张……"）。

你只要回：
- 1　　　　　→ 通过（GPT 自检也通过，就开始做下一张）
- 2　　　　　→ 这张重画
- 直接说哪里不好 → 例如：脸再成熟一点 / 背景不够白 / 裙子换成深蓝色 / 要全身
- 跳过　　　 → 这张先不做，记为"待补"
- 自检　　　 → 想先看 GPT 的检查结果再决定，就回这个
- 文件名　　 → 图片上方没看到文件名小框时回这个，GPT 会再写一遍
- 进度　　　 → 看做到哪了
不满意就一直提意见，直到满意再回 1。
你回了 1，但 GPT 的自检没通过时，它会说原因并自己重画这一张，你再看新图就行。
GPT 重画两次还不满意时，会标 ❌ 交给你决定：你觉得能用就回 1（照样算通过），不行就回 2 或跳过。


六、下载和改名（每张满意的图，回 1 之前先下载）
----------------------------------------------
1. 点图片正上方小框的「复制」按钮，复制的是这张图的文件名，例如 part_sash.png。
   （一定用图片正上方的那个小框，不要用别的图的；没看到小框就回"文件名"。）
2. 点开图片 → 点下载按钮。
3. 弹出「另存为」窗口：
   - 位置选你的 art_pack 文件夹（选过一次以后会记住）
   - 文件名：先全部删掉，再 Ctrl+V 粘贴
   - 点保存
4. 文件名必须是英文，并且和小框里的完全一样。注意不要变成 part_sash.png.png。
5. GPT 后来说"自检没通过、重画"的，新图下载时用同一个名字保存，覆盖旧的就行。
6. 有几个名字写错了也没关系，Claude 会看图帮你改。
   不过图标长得都差不多（都是黑底白图案），图标的名字最好写对。
7. 如果没弹出「另存为」：图片会存到「下载」文件夹，名字类似 "ChatGPT Image ….png"，
   你要手动改名，再移进 art_pack。


七、额度用完 / 换对话接着做
--------------------------
1. Plus 出图有次数限制。官方没公布准数，大约每 3 小时几十张，忙的时候更少。
   提示"已达上限 / 稍后再试"时就先停下，过几个小时再回来。
2. GPT 大约每通过 8 张会给一行【接力码】，例如：
       【接力码】已过 1-9,11-13,22,37｜待补 10｜下一个 14
   每次停下前，先回"进度"，让 GPT 给出最新的接力码，复制到记事本里存好。
3. 一个对话里的图太多会变慢。建议每做 20 张左右就开一个新对话：
   ⓪ 先在旧对话里回"进度"，存好最新的接力码
   ① 在同一个项目里点「新对话」
   ② 发送：
       继续
       【接力码】……（粘贴你存的最后一个接力码）
   ③ GPT 会请你上传 2–3 张已通过的图对齐画风：它说要哪类就传哪类
      （接下来做角色或部件时，再加上风格参考图；做图标、背景、反派时不要传风格参考图）。
   然后它会从下一张接着做。
4. 不记得接力码也可以直接说：从第 25 项继续
   以前跳过的图要一起说，例如：从第 25 项继续，另外补第 10、17 项


八、打包交给 Claude
------------------
1. 全部做完后，GPT 会打印完整清单和一行版权说明。
2. 打开 art_pack 看看图片数量。88 张最好；做不完也行，至少先做完前 42 张（P1），缺的图游戏会先用占位图。
   跳过（待补）的图：GPT 做完最后一项会问你要不要现在补；以后 Claude 的补图请求里也会再列出来。
3. 确认 art_pack 里有第二节第 4 步建好的 credits.txt（没有就现在建，内容一样）。
4. 右键 art_pack 文件夹 → 压缩成 zip：
   - Win11：「压缩为」→「ZIP 文件」
   - Win10：「发送到」→「压缩(zipped)文件夹」
5. 压缩出来的 zip 叫 art_pack.zip（叫什么都行）。按给 Claude 的那一份里《提示词.txt》的步骤，
   把它放进游戏文件夹，交给 Claude 就行。


九、Claude 要你补图时
--------------------
Claude 导入图片后，如果发现有瑕疵或少了图，会给你一段以「【补图请求】」开头的文字。
（你还在按顺序生产时，Claude 只会把要重做的写进补图请求；缺的图在 GPT 里发"继续"和主线接力码接着做就行。）
1. 回到同一个 ChatGPT 项目，点「新对话」，把这段文字整段粘贴进去，发送。
2. GPT 会请你上传几张已通过的同类图当画风参考，照它说的传。
3. 照常审图、下载、改名。补的图存到一个新的英文文件夹里，例如 D:\art_fix1。
4. 把 art_fix1 压缩成 zip（名字随意，例如 补图1.zip），放进游戏文件夹，
   再按《提示词.txt》"补图"那一节，对 Claude 说一句"导入美术"。
5. 一定要把这些补好的图也复制进 art_pack，同名的覆盖旧图。
   不然以后再把整个 art_pack 打包给 Claude 时，旧的坏图会把补好的图盖回去。
6. 补到一半额度用完了：先回"进度"，存好补图接力码（像 【接力码】补图｜已过 13｜待补 47｜剩余 52,60）。
   回来时新开对话，在同一条消息里先写"继续"和这个接力码，再在下面粘贴同一段补图请求，一起发送。
7. 还没在 GPT 里做过任何图的话，不用贴补图请求，直接按第四节发"开始"。
8. 补图做完后，回到你原来做主线的那个对话接着做；或者新开对话，发"继续"和你存的主线接力码。
   下载位置记得切回 art_pack。


十、常见问题
------------
- 画风越来越不一样？
  先回"进度"存好接力码，开一个新对话，发"继续"和接力码；GPT 要哪类参考图，就传那一类里你最满意的 2–3 张。
- 角色看起来太小、像小孩？
  回"更成熟一点，要成年人"。GPT 会加上成年描述重画。所有角色都必须是成年人。
- 被拦截了（说违反内容政策）？
  GPT 会自己把衣服的描述改含蓄再画。还是不行就回"跳过"，以后再补，或者让 Claude 换个提示词。
- 背景不是透明的？
  没关系，纯白底就行，Claude 会自动抠图。
  但灰白相间的格子（棋盘格）不行，那是画上去的"假透明"，回 2 重画。
- 比例不对（该竖的出成了方的）？
  回"比例不对，要 2:3 竖版"。也可以点图片上的「比例 / Aspect ratio」按钮直接改。
- 一张图里出了好几个人或好几个东西？
  角色立绘、Boss、部件只能有一个主体，回 2 重画。
  例外：标题图和卡图本来就可以有几个角色；一对鞘翅、一簇卵、几片晶体这种算一个部件。
- 图上有文字或水印？
  回 2 重画。
- 大概要多久？
  88 张加上重画，大约要出 120–150 次图。按额度算，分 3–5 次做，每次 1–2 小时，
  大概 2–4 天能做完。不用一口气做完，接力码能让你随时接着做。
- 想先看看在游戏里的效果？
  定调批 7 张做完后（GPT 会给一行"定调"接力码，先存好），可以只把这 7 张先打包交给 Claude，
  让它导入后截图给你看，满意再回 GPT 发"继续"和接力码。
- 能用手机吗？
  手机可以审图，但下载和改名在电脑上做更方便。
- Claude 让我上传 ART_PROMPTS.txt？
  加了新种族、换了风格时，清单会变。到游戏文件夹的 docs 里找到 ART_PROMPTS.txt，上传到项目文件里
  （以前传过旧的就先删掉旧的；旧的《美术资产清单与提示词.txt》也从项目文件里删掉，免得 GPT 查到旧提示词），
  然后新开一个对话，粘贴 Claude 给的补图请求。换了风格的话，新的风格参考图也存成 style_ref.png，覆盖旧的。
  上传新清单以后，以前存的接力码就作废了，只按补图请求做。
- 不想打包全部做完再给 Claude？
  可以分批：做完一批就打包一批放进游戏文件夹，对 Claude 说"导入美术"，它会合并导入。
