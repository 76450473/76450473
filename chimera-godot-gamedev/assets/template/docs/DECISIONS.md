# DECISIONS（设计/技术决策记录，新的写在最上面）

格式：日期 · 决策 · 理由 · 被否决的方案

- 2026-10 · 2D 骨骼剪纸式程序化生物 + 材质 shader，而非模块化 3D · AI 能直接写/改/测，部件随骨骼复用动画，组合不爆炸；3D 模块化需要大量人工建模与蒙皮 · 否决：Unity/Godot 3D 模块化角色
- 2026-10 · Godot 4.7 + GDScript 单语言 · 场景/资源是文本、可命令行无头运行与测试、MIT 授权适合开源 · 否决：Unity（授权与二进制/GUID 工作流不利于 AI 驱动开发）、C#（增加构建步骤）
- 2026-10 · 战斗 = 半自动战棋（单位按基因自动行动 + 玩家每回合 3 能量打战术卡）· Build 是核心，同时保留操作；纯数据模拟便于平衡 · 否决：纯卡牌（基因外观无处展示）、纯自走棋（玩家操作太少）
- 2026-10 · 融合 = 形（触发+目标）× 质（动作+状态），按能量预算重算数值 · 组合有逻辑可预测、自动平衡、每对基因两种结果 · 否决：手写 A+B=C 表（攻略一出就死）、纯随机（不可学习）
