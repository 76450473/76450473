这里是美术原图收件箱。Claude 导入时，会先把你的资产包解压到这里，再处理成正式资产，放进 art/ 文件夹。

一、两种放图方式
1. 推荐：把所有图片和 credits.txt 放进一个英文名的文件夹（例如 art_pack），打成一个 zip
   （zip 本身可以叫 美术资产包.zip），放在项目根目录，然后对 Claude 说「导入美术」。
   新建项目时，Claude 会自动发现并导入它。
2. 补图：直接把图片放进这个文件夹，然后说「导入美术」。

二、要求
- 文件名写成资产 id，例如 part_eye_compound.png、body_biped.png、bg_swamp.png。
  资产 id、提示词、比例和背景要求，都在《美术资产清单与提示词.txt》里；
  项目中的 docs/ART_TODO.md（缺失的）和 docs/ART_PROMPTS.txt（全部）里也有。
  名字写错也没关系，Claude 会打开图片看是什么，再帮你改名。
- 背景：角色立绘、部件、Boss 用纯白平底（能直接导出透明背景更好）；图标用纯黑平底；背景图和卡图正常出画面。
- 主体要有粗的深色描边，并且尽量占满画面。
- credits.txt 写一行：你用的工具或模型，以及授权（用 UTF-8 编码保存）。例如：Midjourney v7，付费订阅可商用
- Windows 请先在资源管理器里勾选「查看 → 显示 → 文件扩展名」，再给图片改名，避免变成 .png.png。

三、导入之后
- 处理完的原图会移到 _done/，资产包会移到 _packs/；用不了的图（avif、heic、gif、psd 等格式或文件损坏）会移到 _failed/，换成 PNG 再放进来即可。
- png、jpg、jpeg、webp 格式都可以。缺的资产会自动用程序画的占位图代替，不影响游戏运行。
