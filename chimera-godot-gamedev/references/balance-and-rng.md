## 1. 平衡哲学

- **不追求所有 Build 一样强**，而是让**每个强势 Build 都有明确的克制**：
  - 虫海怕范围伤害，巨兽怕控制，毒流怕净化和再生。
  - 再生怕重伤，护甲流怕穿透和毒，召唤流怕满格。
  - 同时，玩家也要有机会通过选路或临时补一个基因来弥补弱点。
- **纯血和混血都要能玩**。纯血共鸣、稳定度和跨族系数这三个旋钮控制两者的平衡。
- **永久成长不加强度**，否则随机性会失去意义。
- 数字是用来服务玩家体验的。模拟结果漂亮但玩起来无聊，同样是失败。等 M2 之后可以请用户试玩。

## 2. 工具：`tools/balance_sim.gd`

```bash
godot --headless --path . --script res://tools/balance_sim.gd -- n=400 seed=1 tier=2 out=reports/balance_t2.csv
```

- **玩家方**：从可玩种族中随机生成合法 Build（允许混入其他种族的基因），基因预算倍率为 1.0；战术卡随机打出。
- **敌人方**：EnemyFactory 生成，所在生态区随机，有 25% 的概率是精英。
- **输出**：
  - 总胜率、平局率、平均回合数、触发上限出现的比例。
  - **按敌族统计的玩家非胜率**。
  - **按基因统计的胜率偏差**：带有某个基因时的胜率减去总体胜率。偏差超过 15 个点且样本数 ≥ 20 的，会标上 `<-- CHECK`。
- **随机出牌机器人比真人弱**，所以目标区间比真实体验要宽松一些。M3 之后可以加一个"贪心策略"作为第二档参考。

## 3. 目标区间（每次改数值后都要对照）

| 指标 | 目标 |
|---|---|
| 玩家胜率 tier 1 / 2 / 3 | 65–80% / 55–72% / 45–65% |
| 平均回合数 | 4–9 |
| 平局率 | < 3% |
| 触发上限比例 | < 1% |
| 各敌族的玩家非胜率 | 最大值减最小值 ≤ 20 个点 |
| 单个基因的偏差 | 绝对值 ≤ 15 个点（样本 ≥ 20） |
| 融合产物的 power | 不超过原料之和 × 1.6 + 1（已由测试保证） |

把每次的结果写进 PROGRESS.md 的"最近一次验证"，方便看出变化趋势。

## 4. 调参流程与手段优先级

1. 找出偏离目标的指标，**先猜原因**：是单个基因、整个种族，还是某种机制本身？
2. 每次只改一处，然后重跑 `n ≥ 400` 的三个 tier。
3. 手段按优先级从高到低：
   1. **amount**：效果的数值
   2. **trigger 或 target**：比如把 on_attack 改成 on_hit，把 enemy_area 改成 other
   3. **stats**：基础数值
   4. **stability 成本**：限制它能和多少东西叠加
   5. **rarity**：降低出现频率
   6. **power 表本身**：某一类效果被系统性地估错时才动它
   7. **单位模板**的 hp、atk（影响一整个种族）
4. **永远不要在代码里写特例**（比如"如果是某某基因就减半"）。
5. 把结论写进 DECISIONS.md，例如"兽族 atk -1，原因是 tier 3 的非胜率达到 88%"。

## 5. 退化策略的检测与对策

| 症状 | 检测 | 对策 |
|---|---|---|
| 无限连锁（死亡、召唤、死亡……） | trigger_cap 比例上升 | 降低 TRIGGER_FREQ，召唤物不带基因，设置深度上限 |
| 僵局（双方都打不死对方） | 平局率、平均回合数上升 | 环境侵蚀提前；再生和护甲设上限 |
| 单一基因统治 | 某个基因偏差 > 15 且出现率高 | 降低 amount 或提高 stability 成本 |
| 第一回合就秒杀 | 平均回合数 < 3 | 提高单位 hp；限制 on_round_start 的伤害 |
| 某个种族永远赢不了 | 按敌族统计的数据 | 调整种族模板或协同模板 |
| 融合产物超模 | test_power_budget_in_band 失败 | 降低 budget_ratio 或 max_amount |

## 6. 奖励随机：权重、保底、去重（M2 实现，使用 reward 流）

- **基因候选的权重**：
  - 60% 和玩家当前 Build 的标签重合（协同偏向）
  - 30% 中性
  - 10% 野性：来自当前生态区敌族的其他种族
- **保底**：连续 3 次奖励都没有出现稀有或更高品质时，第 4 次必定出现。
- **去重**：同一个界面里不会出现重复选项；最近 2 次奖励出现过的基因，权重 ×0.3。
- **重抽**：每幕给 1 次免费重抽，黑市可以买更多次。
- **精英奖励**：品质提高一档，必定附带一个样本。
- **不要**让玩家通过退出重进来刷奖励：奖励在进入节点时就生成好并写入存档。

## 7. 地图生成约束（M2 实现，使用 map 流）

- 每幕分 6–7 层，每层 2–4 个节点，总共 12–15 个节点。每个节点有 1–3 条出边，不允许出现断路。
- 前 2 层只有战斗和事件；第 1 个精英不早于第 3 层出现。
- 每幕至少 1 个遗迹（融合台）和 1 个栖息地；Boss 之前的最后一层必有栖息地。
- 黑市和异变池每幕各最多 1 个。
- 选路要有意义：至少存在两条风险或收益明显不同的路线。可以写一个测试，检查从起点到 Boss 每条路径上的精英数量是否有差异。
- 地图生成好后存进 RunState，读档时不重新生成。

## 8. 敌人多样性

- 同一幕内，连续两场精英不能使用同一个协同模板。
- 普通战斗的敌族按生态区的 enemy_races 轮换，每一层至少出现两种敌族。
- Boss 的辅助基因每局都会变，核心机制不变。
- 敌人的 tier 随层数增长：第 1–2 层为 1，第 3–5 层为 2，第 6 层以后为 3；每往后一幕，tier 再 +1（上限 3），差距用预算倍率补上。

## 9. 随机的边界：输入随机，输出确定

- **随机的部分**：玩家看到的选项（奖励、地图、敌人组合、商店），以及战斗里速度相同时的先后、random_enemy 的目标。
- **确定的部分**：伤害、状态结算、融合结果（突变除外）。
- 所有概率都要**显示给玩家**：突变的三档概率、过载风险、配方提示。
- 种子可见并可分享，在世代总结界面显示，便于复现 Bug 和做挑战。
