# 里程碑路线图（一次只做一个；每条验收都要有证据）

通用验收（每个里程碑都要满足）：`godot_check.sh` 输出 ALL CHECKS PASSED；新增的 sim 逻辑都有测试；画面相关的改动有截图并且你亲自看过；PROGRESS.md 已更新；已 git commit。

## M0 地基（模板已完成）
`new_project.sh` 一条命令建出项目。数据校验、确定性战斗、融合、敌人生成、程序化生物、材质 shader、33 项测试、平衡模拟、截图工具、CI 全部就绪。
**验收**：全绿；截图 `screenshots/m0.png` 中 6 个演示单位的血统一眼可辨。

## M1 一场可玩的战斗
- `scenes/battle.tscn` + `src/view/battle_view.gd`：2×3 对 2×3 的棋盘（坐标见 visual-system §10），用 CreatureView 当棋子，敌方 `facing = -1`。
- 事件播放器：按 systems-spec §12 播放 attack、damage 飘字、status 图标、death、summon、trigger 闪光；支持 1×、2×、4× 倍速和跳过。
- 每个单位的 UI：血条、护甲、状态图标、基因图标（悬停时显示 `GeneMath.describe_gene` 生成的描述）。
- 手牌和能量 UI：抽 4 张，3 点能量；可以指定目标的卡要能选目标；有"结束回合"按钮。敌人意图可见（攻击的列，以及会触发的基因）。
- 胜利和失败界面；从主菜单进入"快速战斗"（随机玩家队伍对随机敌人）。
- 背景、状态图标、卡框优先通过 `ArtLibrary` 取图（bg_、icon_status_、card_frame），取不到就画占位。用户提前上传了这些图，就直接生效。
- 打包 CJK 字体（OFL）并在 CREDITS.md 登记；用 `ui/theme.tres` 统一风格。
- 新增一个 `PlayerController`，sim 和 UI 之间的唯一桥梁：只调用 `begin_round`、`play_card`、`resolve_round`。

**验收**：用鼠标能完整打完一场战斗；截图里能看清"规划阶段"和"执行中"两种状态；连续 20 场快速战斗冒烟（可以用自动策略）没有 ERROR；全程 60 FPS。

## M2 一局远征：第一幕纵切片
- `RunState` 加存档（systems-spec §9），使用 `Game` autoload 和 `Rng.new_run(seed)`。
- 地图生成器：用 map 流生成 12–15 个节点的分支 DAG，满足 balance §7 的约束。地图界面能看到已走过的路线和接下来可选的节点。
- 节点：战斗、精英、栖息地（治疗 / 招募 / 移植）、事件（4 个，数据写在 `data/events.json`）、黑市、Boss（腐巢母皇加护卫）。
- 奖励三选一（基因 / 卡 / 资源），权重和保底见 balance §6。
- Boss 解剖三选一；世代总结界面；标题界面；始祖选择（人族、虫族）。
- 中途存档，退出再进来能继续。

**验收**：从标题界面到击败腐巢母皇能完整走通一遍；死亡后进入总结；用同一个种子重开，地图和第一场战斗的敌人完全相同（写测试证明）；存档后读档继续，状态一致（写测试证明）。

## M3 基因工坊与平衡
- 基因工坊界面：植入或移除基因、稳定度条（显示过载和纯血状态）、融合台（放入形和质，预览 `GeneFusion.predict`，提示"可能触发未知配方"）、过载时的突变概率提示、突变结果演出。
- 图鉴：已发现的基因、配方（未发现的只显示 hint）、物种（自动渲染的卡面，见 visual-system §11）。
- 平衡：把 PROGRESS 里列出的已知平衡问题调到 balance §3 的目标区间内；新增 4–8 个基因，让每个可玩种族至少有 2 个能走通的 Build 方向。
- 在 tools 里新增 `fusion_report.gd`：枚举所有可融合的组合，统计 power 分布和配方命中率，找出离群值。

**验收**：在 tier 1–3 下，balance_sim 的各项指标都落在目标区间内；融合预览和实际结果一致（写测试）；截图包含工坊、融合台、图鉴三个界面。

- 世界种子：开局三选一，决定生态区顺序、生态规则和奖励池的偏向。
- 内容扩到 gdd §14 中 M4 那一行的规模；新增 3 个精英协同模板；事件总数达到 12 个。
- 菌族解锁为可玩种族，兽族和晶族通过谱系解锁的接口先预留。

**验收**：三幕能完整通关一次（可以用调试作弊加速，但每场战斗都必须真实模拟）；每个 Boss 都有"它教给玩家什么"的测试场景；平衡全绿。

## M5 正式美术落地（管线在 M0 就已就绪，用户随时可以上传）
- 和用户一起把 P1、P2 美术补齐（art-pipeline §4）。每次导入都要截图质检，错位只改 sidecar 不改代码。
- 每个种族的部件和骨架都有正式美术；三个生态区各有背景；卡框、UI 主题（ui_panel、ui_button 做成九宫格 StyleBox）、全部图标就位。

## M7 观察、敌族进化竞赛与终局
- 敌人的基因先显示为"?"，发动后揭示；解析卡可以直接揭示；只有揭示过的基因才能取样。

- 终幕 Boss「原种」：基因池来自本局玩家用过的基因；实现三个结局（纯血 / 奇美拉 / 共生）。

**验收**：写测试证明诱骗策略确实有效（先用毒、后切物理，对手的预算被浪费）；三个结局都能触发。
