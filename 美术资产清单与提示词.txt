《奇美拉纪元》美术资产清单与提示词（共 82 项）
==================================================

这份文件说明：要生成哪些图、每张图叫什么名字、用什么提示词，以及做完后怎么打包。
全部做完后，把图片打包成一个 zip，和 skill、《提示词.txt》一起交给 Claude 就行。

做不完也没关系：缺的图，游戏会用程序画的占位图代替，照样能开发、能玩。
建议至少把 P1 的 40 张做完，游戏前期的画面基本都靠这一批。


一、整体步骤
------------
1. 先做第三节的"定调批"6 张，确认风格满意。最好先生成一张"风格参考图"（见第三节开头）。
2. 按第五节的清单逐项生成，顺序是 P1 → P2 → P3。
   每张图都按【】后面的文件名保存，例如 part_eye_compound.png。
   文件名必须用清单里的英文名，不要改成中文。
3. 新建一个文件夹，命名为"美术资产包"，把全部图片放进去，再新建一个 credits.txt，写一行：
       你用的工具或模型，以及授权。例如：Midjourney v7，付费订阅可商用
4. 右键这个文件夹，压缩成 美术资产包.zip。
5. 按《提示词.txt》的步骤，把 zip 放进游戏项目文件夹，然后启动 Claude。
   Claude 会自动解压、抠图、按种族上色、对齐，然后截图给你看效果。
   不满意的图，它会告诉你原因，并给出改好的提示词。


二、四条硬要求（决定能不能自动抠图和上色）
----------------------------------------
1. 背景：
   - 部件、骨架、Boss 用纯白平底背景
   - 图标用纯黑平底背景
   - 战斗背景、卡图、卡背、界面图正常出完整画面
   导入工具是从图片四边往里"泛洪"去背景的，所以背景必须是没有渐变、没有纹理的纯色。
2. 主体外面要有一圈闭合的粗深色描边。
   描边就是去背景时的"墙"，有缺口的话，背景会漏进主体里。
3. 部件和骨架要画成灰度图，只有提示词里说的发光部位用鲜绿色。
   游戏会按宿主种族自动上色：灰度变成种族的配色，鲜绿变成元素光（毒是绿光、易伤是紫光……）。
   所以一张复眼图放在人族身上和虫族身上都协调，不用每个种族各画一套。
4. 主体要占满画面（60% 以上），分辨率 1024 以上。
   主体太小的话，放大后会发糊。

另外：
- 一律侧视、朝右（Boss 立绘朝左），一张图只画一个东西，不要文字、不要水印。
- 能直接输出透明背景 PNG 的工具也可以用，导入时会自动识别。

四、不同工具的用法
------------------
- Midjourney：
  提示词末尾加 --ar 比例 --style raw --no 反向提示词内容。比例按每一项的要求填，例如 --ar 1:1。
  风格统一：加 --sref 风格参考图的链接。
- Stable Diffusion / ComfyUI：
  提示词和反向提示词分别填进对应的栏，固定模型和采样器；统一风格用 IP-Adapter 加参考图。
- GPT 图像 / DALL·E：
  没有反向提示词栏，在提示词末尾加一句 "Avoid: 反向提示词内容"。可以选透明背景。
- 即梦 / 通义万相 / 可灵 / 其他国内工具：
  可以直接粘贴英文提示词；请关闭"智能扩写/提示词优化"，否则会自动加背景；比例按要求选；上传风格参考图。
- 偏好中文提示词的，可以用这段中文风格锁定，后面接每一项的主体描述（主体描述可以翻译成中文）：
  2D 游戏素材，暗黑生物幻想，禁忌博物志画风，单个独立物件，侧视朝右，单色灰度明暗绘画，平涂赛璐璐加一处柔和高光，整体有粗细均匀的近黑色描边，轮廓清晰，主体占满画面，纯白色平底背景，无文字、无投影、无边框。

六、常见问题
------------
- 图片带了背景纹理或渐变：重新生成时强调 "plain flat pure white background, no gradient, no texture"；工具有背景选项就选纯色。
- 文件名能用中文吗：不能，请用清单里的英文名。名字写错了 Claude 也会看图帮你改，但写对最省事。
- 能把多个物件拼在一张图里吗：不行，一张图只画一个物件。
- 尺寸和格式：生成 1024 以上即可，导入时会自动缩放；png、jpg、jpeg、webp 格式都行。
- 生成出来带颜色怎么办：部件和骨架需要灰度图。导入时 Claude 会提醒你，并给出强调灰度的新提示词。
- 版权：AI 图的版权以你所用工具的条款为准。游戏要开源发布的话，确认你的订阅允许公开分发。
