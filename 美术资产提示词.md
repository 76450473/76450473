# 《奇美拉纪元》美术资产提示词（共 82 项）

> 这份文件和项目里的 `docs/ART_PROMPTS.md` 内容一致，后者由 `tools/art_audit.gd -- full` 自动生成。
> 游戏内容有变化时（新基因、新生态区、新卡牌……），Claude 会重新生成，并把新增的缺失项写进 `docs/ART_TODO.md`。
> **缺图不影响游戏运行**，缺的部分会自动用程序化占位美术代替，所以可以一边开发一边慢慢补。

## 一、整体流程

1. 按下面的清单生成图片（建议先做第三节的"定调批"，满意后再批量生产）。
2. 文件名**改成清单里的资产 id**，例如 `part_eye_compound.png`，然后放进项目里的 `art_inbox/` 文件夹。名字写错也没关系，Claude 会看图帮你改。
3. 在 `art_inbox/credits.txt` 里写一行：你用的工具或模型，以及授权（例如"Midjourney v7，付费订阅可商用"）。
4. 对 Claude 说：**「导入美术」**。它会抠图、裁边、转灰度、缩放、计算挂点，截图检查效果，然后告诉你：
   - 哪几张需要重做，以及**改好的完整提示词**
   - 还缺哪些
5. 重复以上步骤，直到 P1 补齐，再做 P2。

## 二、必须遵守的四条（决定能不能自动处理）

| 规则 | 原因 |
|---|---|
| 部件、骨架、Boss 用**纯白平底背景**；图标用**纯黑平底背景**；背景图和卡图正常出画面 | 导入工具从图片边缘向内泛洪去背景，背景必须是纯色 |
| 主体要有**闭合的粗深色描边** | 描边是去背景时的"墙"，有缺口就会漏进主体 |
| 部件和骨架画成**灰度图**，只有提示词里说的发光部位用**鲜绿** | 游戏会按宿主的种族自动上色：灰度变成种族配色，鲜绿变成元素光（毒、易伤……）。所以一张复眼图放在人族和虫族身上都协调 |
| 主体**占满画面**（60% 以上），生成分辨率 1024 以上 | 太小的话放大后会发糊，导入时会提示你 |

另外：侧视、**朝右**；一张图只画一个东西；不要文字、不要水印。能直接输出透明背景 PNG 的工具也可以用，导入时会自动识别。

## 三、建议的"定调批"（先做这 6 张，验证风格和流程）

`body_biped`（人形骨架）、`body_hexapod`（虫形骨架）、`part_eye_compound`（复眼）、`part_sac`（毒腺囊）、`icon_status_poison`（毒图标）、`bg_swamp`（腐沼背景）。

导入后让 Claude 截图给你看。效果满意的话，把这几张当作**风格参考图**，后面所有的图都带上它们：Midjourney 用 `--sref`，即梦等工具上传参考图，SD 用 IP-Adapter。这样整套美术的风格才统一。

## 四、不同工具的用法

| 工具 | 怎么填 |
|---|---|
| Midjourney | 提示词末尾加 `--ar 1:1 --style raw --no 反向提示词内容`（比例按每一项的要求填）；风格统一用 `--sref 链接` |
| Stable Diffusion / ComfyUI | 提示词和反向提示词分别填；固定模型和采样器；需要统一风格时用 IP-Adapter 加参考图 |
| GPT 图像 / DALL·E | 没有反向提示词栏，在提示词末尾加 `Avoid: 反向提示词内容`；可以选透明背景 |
| 即梦 / 通义万相 / 可灵 | 可以直接粘贴英文提示词；**关闭"智能扩写/提示词优化"**（否则会自动加背景）；比例按要求选 |

中文风格锁定（偏好用中文提示词时，放在中文描述的前面）：
> 2D 游戏素材，暗黑生物幻想，禁忌博物志画风，单个独立物件，侧视朝右，单色灰度明暗绘画，平涂赛璐璐加一处柔和高光，整体有粗细均匀的近黑色描边，轮廓清晰，主体占满画面，纯白色平底背景，无文字、无投影、无边框。
