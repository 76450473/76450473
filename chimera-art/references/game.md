# 这些图在游戏里怎么用（出图前先读）

## 游戏

《奇美拉纪元》是一款开源 2D 肉鸽游戏：玩家是一个弱小新物种的"始祖意志"，带着子嗣远征，打败其他种族和 Boss，夺取它们的**基因**，把基因**移植、融合**到自己的单位身上，进化出前所未见的"奇美拉"物种。核心卖点是**看得见的血统**：每个基因都要能在单位身上看出来，玩家看一眼敌人就能读懂它的 Build。

## 世界观（决定画面气质）

- 世界叫**源壤**：所有生命都来自同一个原初基因组「原种」。每个纪元末，「谱系之树」会枯萎一次（**大寂灭**），只有一条血脉能延续。
- 六大种族（人、虫、菌、兽、晶、魂）各派出本族的**顶点物种**向世界中心进军。图里每族的角色，就是这个种族活着的顶点形态：衣着像是从本族的生物材料里**长出来**的（人族自己织的丝钢和玉、虫族甲壳、菌族菌丝、兽族毛皮骨角、晶族晶格、魂族灵雾），不是商店里买的时装。
- 统一的世界印记：皮肤和衣缘上淡淡发光的**基因脉络纹**（各族颜色不同）。
- 反派是被大寂灭扭曲的同族**顶点掠食者**：更大、更凶、本族器官过度生长。
- 图鉴、卡框、界面的感觉是一本**禁忌博物志**（物种图谱）。
- 整体：华丽的二次元仙侠立绘 + 哥特未来 + 生物幻想；美而带一点诡异，不是轻松的时装秀。所有角色都是成年人。

## 机制（决定图要怎么画）

- **一个单位 = 一张角色立绘（body_）+ 若干基因器官（part_）**。器官贴在立绘的固定位置上：头顶（head）、眼部（eye）、肩背（back）、胸口（core）、躯干（torso，如肩带、胸甲）、前臂和手（limb）。
- **融合会混种**：一个人族角色身上可能同时长着虫族复眼面罩、菌族孢子冠和晶族碎片。所以器官要能贴到任何一族的身体上都不违和，靠颜色认出它来自哪一族。
- 皮肤类基因是游戏里叠在立绘上的花纹和颜色，不用单独出图。
- 敌人和玩家用同一套基因，反派立绘上也会贴器官。
- **显示尺寸很小**：战斗中角色立绘大约只有 140 像素高（反派约 170），器官只有几十像素，图标是 32 像素。

## 所以出图时必须做到

1. 角色立绘（`body_`，我方和反派都算）的**头顶、肩背、前臂、胸口保持干净**：不戴帽子、兜帽、头盔、王冠、高发饰，不披斗篷、翅膀、大领子，袖子贴身，手里不拿东西，不戴大件首饰。种族特征（耳朵、触角、尾巴、晶体发丝）可以有，但要贴着身体、不挡这些位置。
2. **缩小后还认得出**：轮廓清楚，每族的主色一眼能分辨（人族蓝银、虫族红黑、菌族象牙绿、兽族银灰琥珀、晶族冰蓝白、魂族黑紫）。
3. 器官画成**基因器官**：生物质感 + 一点华丽装饰，接身体的那一端看得清楚，单独一件、没有人。
4. 背景是源壤的生态区：地面中下部留空给战斗，远处可以有巨大的谱系之树根系和发光的基因脉络。
5. 不要为了好看加清单里没写的东西（尤其是帽子、披风、武器），那会和游戏里贴上去的器官打架。

Boss 大图（`boss_`）、卡图、背景是单独展示的，不贴器官：Boss 可以戴王冠、有大裙摆，照清单写的画。
