《奇美拉纪元 Chimera Epoch》Claude 端：提示词与使用说明
=====================================================

你一共有两份文件：
  【给 Codex 的】给Codex的文件.zip，解压出 chimera_art 文件夹（美术技能已经装在里面），先看里面的《Codex使用说明.txt》
               → 用 Codex 和你的 ChatGPT 订阅生产全部美术图片（不花 API 的钱）
  【给 Claude 的】给Claude的文件.zip，里面是 chimera-godot-gamedev.zip（skill）、提示词.txt（本文件）
               → 让 Claude 用 Godot 把游戏做出来
  （解压后如果中文文件名变成乱码，用 7-Zip 或 Bandizip 解压就好。）

总流程：
  ① 在 Codex 里按《Codex使用说明.txt》生产美术：你选一次画风，Codex 出图、自检、预选，你在审核页里审
     → Codex 打包出 outbox\art_pack.zip
  ② 安装 Godot 和 Claude Code，安装 skill
  ③ 新建一个空的游戏文件夹，放进 art_pack.zip，在这个文件夹里启动 Claude Code，发一句提示词
  ④ Claude 建项目、导入美术、逐张检查并截图给你看，然后开始开发
  ⑤ 有缺的图或者有瑕疵的图，Claude 会给你一段「补图请求」：
     你把它粘贴给 Codex 补做，Codex 出一个 fix_01.zip，你再交给 Claude，直到美术全部到位

美术风格（已经写进 skill 和全部提示词）：
  二次元 × 仙侠游戏立绘 × 哥特未来。每个种族是一名拟人化的成年角色，我方以女性为主（5 女 1 男）：
  人族剑修女侠、虫族主角、蘑菇仙子、狼族少主（男）、晶灵机娘、幽灵贵女。
  画风参考仙侠游戏立绘（汉服式长裙、高开衩、披帛、玉簪），甜美、迷人但有分寸。
  敌人是每族的反派版本：更高大、更强、一看就是反派，男女都有。基因部件是戴在角色身上的配饰（面罩、吊坠、长枪、鞘翅……）。
  所有角色都是成年人，不出现裸露。


第一步：准备美术资产包
----------------------
按《Codex使用说明.txt》在 Codex 里生产。图片的文件名和 credits.txt 都由 Codex 自动弄好，
你只要在 Codex 里发「$chimera-art 打包」，就会得到 D:\chimera_art\outbox\art_pack.zip。
不用等全部做完：先做完定调批或 P1 也可以开始，缺的图游戏会先用占位图顶上，以后再补。
（用备用的 ChatGPT 网页版或别的工具出图也行：图片按清单文件名保存，加一个 credits.txt，压缩成 zip 就行。）


第二步：安装 Godot 4.7.2（选"标准版"，不要选 .NET 版）
---------------------------------------------------
下载地址：https://godotengine.org/download

- Windows：
  解压到 C:\Godot\，里面有两个 exe，命令行要用带 _console 的那个。
  打开 PowerShell（按 Win 键，输入 PowerShell，回车），执行一次下面这句（执行后要重开终端才生效）：
      setx GODOT_PATH "C:\Godot\Godot_v4.7.2-stable_win64_console.exe"
  （文件名以你实际解压出来的为准）
- macOS：
  brew install --cask godot，或者下载 dmg 拖进"应用程序"。
- Linux：
  解压后 chmod +x，再把 GODOT_PATH 设为它的完整路径。


第三步：安装 Claude Code（Claude 必须在你自己的电脑上运行，才能驱动 Godot）
----------------------------------------------------------------------
- 最简单的方式：下载 Claude 桌面版 App，使用里面的 "Code"（代码）功能。
- 或者用终端安装：
      Windows PowerShell： irm https://claude.ai/install.ps1 | iex
      macOS / Linux：      curl -fsSL https://claude.ai/install.sh | bash
- Windows 还要装 Git for Windows：https://git-scm.com/downloads/win
  skill 里的脚本要靠它自带的 Git Bash 才能运行。
- 需要 Pro、Max、Team 或 Enterprise 账号。


第四步：安装 skill
------------------
先把 给Claude的文件.zip 解压（右键 →「全部解压缩」），得到 chimera-godot-gamedev.zip 和本文件。
chimera-godot-gamedev.zip 就是 skill，下面装的就是它。

Windows（最不容易出错的做法）：
  1. 打开 PowerShell（按 Win 键，输入 PowerShell，回车），执行：
         mkdir $env:USERPROFILE\.claude\skills
     如果提示"已存在"，没关系。
  2. 打开资源管理器，在地址栏输入 %USERPROFILE%\.claude\skills 后回车，打开这个文件夹。
  3. 双击 chimera-godot-gamedev.zip（不用解压），能看到里面有一个 chimera-godot-gamedev 文件夹。
     把这个文件夹直接拖进第 2 步打开的 skills 窗口。
  4. 检查：最终路径必须是 C:\Users\你的用户名\.claude\skills\chimera-godot-gamedev\SKILL.md。
     如果中间多了一层同名文件夹，Claude 会找不到 skill，要把里面那层拖出来，放到 skills 下面。

macOS / Linux：
  解压 zip 后，把 chimera-godot-gamedev 文件夹放到 ~/.claude/skills/ 下面，
  最终路径是 ~/.claude/skills/chimera-godot-gamedev/SKILL.md。

（可选）在 claude.ai 网页版里也想用：到设置里的 Skills 页面上传 chimera-godot-gamedev.zip。
不过网页聊天没法运行你电脑上的 Godot，做游戏一定要用 Claude Code。


第五步：新建游戏文件夹，放入资产包
----------------------------------
新建一个空文件夹，例如 D:\games\chimera（没有 D 盘就建 C:\games\chimera，路径用英文，不要放在桌面），
把第一步打包好的 zip 放进去（art_pack.zip、美术资产包.zip，叫什么都行）。
里面不要放别的东西。这些 txt、skill 压缩包放进去也没关系，Claude 会自动忽略它们，也不会把它们提交到 git。
游戏文件夹和 Codex 用的 D:\chimera_art 是两个不同的文件夹，不要把一个放进另一个里面。


第六步：在这个文件夹里启动 Claude Code
------------------------------------
- 桌面版：打开 Code，选择这个文件夹。
- 终端：先 cd 到这个文件夹，再输入 claude。
Claude 运行脚本时会请求权限，选"允许，以后不再询问"会省事很多。
（可选）想让 git 提交记录里显示你的名字，在第七步之前，在 PowerShell 执行一次：
    git config --global user.name "你的名字"
    git config --global user.email "你的邮箱"
不设置也能正常开发：项目会自动用默认身份"Chimera Dev"提交。
如果项目已经建好了才想改，就在游戏文件夹里（不带 --global）再执行一次这两句。


第七步：发送一句话提示词（复制下面这一整行）
------------------------------------------

/chimera-godot-gamedev 我把美术资产包放在当前文件夹了。请在当前文件夹从零开始做《奇美拉纪元》：建项目并导入资产包，逐张检查美术并截图给我看；缺的或有瑕疵的图，给我一段可以直接粘贴给 Codex 的补图请求；然后按路线图一个里程碑一个里程碑开发下去，每完成一个里程碑用中文汇报并附截图，需要我拍板的事再问我。

（如果输入 / 之后没有弹出这个 skill，就把开头改成："使用 chimera-godot-gamedev 这个 skill，……"）

Claude 接下来会自动做这些事：
  找到 Godot → 在当前文件夹建项目 → 解压并导入资产包 → 抠图、对齐
  → 跑完整检查和测试 → 截 5 张图（美术检查台四页加基因实验室）→ 汇报美术情况和补图请求
  → 开始开发第一个里程碑（可操作的战斗）。


补图：缺图或者有瑕疵的时候
--------------------------
1. Claude 会给你一段以「$chimera-art 【补图请求】」开头的文字，里面写着要补的文件名、清单编号和原因。
2. 在 Codex 里点「新对话」（文件夹还是 D:\chimera_art），把这一整段粘贴进去，发送。
3. Codex 只补这些图，照常自检；好了以后双击 D:\chimera_art 里的 review（开着的按 F5 刷新）审核，和第一次生产一样。
4. 全部通过后，Codex 会自动更新它的 art_pack，并生成 outbox\fix_01.zip（只含这次补的图）。
   把 fix_01.zip 放进游戏文件夹。
   （用备用 ChatGPT 网页版的话，照《GPT使用说明.txt》第九节做。）
5. 对 Claude 说：
   /chimera-godot-gamedev 导入美术：处理新的图片，截图检查效果，告诉我还有哪些要重做或缺失（附补图请求）。
重复几次，直到美术全部到位。少量图片也可以不打包，直接放进游戏文件夹里的 art_inbox 文件夹。


之后每次继续（换新会话也一样）
------------------------------
/chimera-godot-gamedev 继续开发：先读 docs/PROGRESS.md，从"下一步"接着做，做完当前里程碑再向我汇报。

进度都记在项目的 docs/PROGRESS.md 里，不会丢。会话中途被打断时，直接说"继续"就行。


常用指令（按需复制）
--------------------
· /chimera-godot-gamedev 现在还缺哪些美术？给我一段补图请求，先补 P1。
· /chimera-godot-gamedev 这张 part_xxx 不满意：＿＿。帮我写进补图请求里，写清楚怎么改。
· /chimera-godot-gamedev 我想换一种美术风格：＿＿。请改风格锁定，重新生成全部提示词，并告诉我要重做哪些。
· 跑一遍平衡模拟，把不达标的数值调回目标区间，然后告诉我改了什么、为什么改。
· 截一张现在的战斗画面给我看，并按视觉验收清单自己检查一遍。
· 我想加一个新种族「＿＿」，主题是＿＿。请按扩展清单把它加进去，同步美术清单，并做平衡。
· 我想加一个 Boss，它的核心机制是＿＿，要让玩家学会＿＿。
· 我玩下来觉得＿＿不好玩，请分析原因，给出 2–3 个改法，等我选。
· 准备开源发布：补齐 README、CONTRIBUTING、CHANGELOG，并检查素材授权。先不要推送，等我确认。

（换了风格或者加了新内容，美术清单会变：Claude 会让你把游戏文件夹里的 docs\ART_ASSETS.json
  复制到 D:\chimera_art\，再把补图请求发给 Codex，它会自动换上新清单。
  用备用 ChatGPT 网页版的话，是把 docs\ART_PROMPTS.txt 上传到 ChatGPT 项目的文件里。）


常见问题
--------
· Claude 说找不到 Godot：
  检查 GODOT_PATH 是否设置正确（Windows 要指向 _console.exe），然后重启终端或 Claude。
· 想自己玩玩看：
  双击 C:\Godot 里不带 console 的那个 Godot exe → 在项目管理器里点「导入」
  → 选游戏文件夹里的 project.godot → 打开后按 F5。
  演示场景的按键：D 演示组　R 随机敌族　F 随机融合　B 重跑战斗。
· 图片文件名没改对：
  没关系，Claude 会打开图片看是什么，再帮你改名。
· 导入后部件位置歪了：
  直接告诉 Claude"xxx 的位置不对"，它会调对齐参数并重新截图，不用重画。
· 美术还没做完能开始做游戏吗：
  能。缺的图会先用程序画的占位图，等你补上再替换。
· 开源吗：
  Godot 引擎是 MIT 协议，免费、不抽成。项目默认代码用 MIT，美术用 CC BY-SA 4.0。
  Codex / ChatGPT 生成的图会在 CREDITS.md 里按 credits.txt 注明来源。发布前请确认 OpenAI 当前的使用条款。
  Claude 只在本地提交，推送到 GitHub、发布到 itch.io 之前都会先问你。
