《奇美拉纪元 Chimera Epoch》给 Claude 的提示词与使用步骤
======================================================

你手上应该有三样东西：
  1. chimera-godot-gamedev.zip       ← skill：做这款游戏所需的全部知识、工具和已验证的项目模板
  2. 提示词.txt                      ← 本文件：安装步骤，以及发给 Claude 的话
  3. 美术资产清单与提示词.txt        ← 全部美术资产的清单和生图提示词（手动出图时用；GPT 模式下当参考）

美术风格（已经写进 skill 和全部提示词）：
  二次元 × 仙侠游戏立绘 × 哥特未来。每个种族是一名拟人化的成年角色，我方以女性为主（5 女 1 男）：
  人族剑修少女、虫族主角、蘑菇仙子、狼族少主（男）、晶灵机娘、幽灵贵女。
  画风参考仙侠游戏立绘（汉服式长裙、高开衩、披帛、玉簪），甜美、性感但有分寸。
  敌人是每族的反派版本：更高大、更强、一看就是反派，男女都有。基因部件是戴在角色身上的配饰（面罩、吊坠、长枪、鞘翅……）。
  所有角色都是成年人，不出现裸露。这也是 OpenAI 的规则，太暴露的描述会被拦截。
  想换风格，随时跟 Claude 说（见下面"美术常用指令"）。

美术有两种做法，可以混用：
  A. GPT 自动生成（推荐）：你只提供一个 OpenAI Key。Claude 生成图片、先替你初审，
     再把挑好的图给你复审，你点"通过 / 不要"就行。
  B. 自己生成：按《美术资产清单与提示词.txt》自己出图，打包成 zip 交给 Claude。

总流程：
  准备 Key（或资产包）→ 安装 Godot 和 Claude Code → 安装 skill → 新建工作区文件夹
  → 发一句提示词 → Claude 建项目、生成美术并初审 → 你复审 → 边出图边开发


第一步：准备美术（二选一）
--------------------------
A. GPT 自动生成
  1. 打开 https://platform.openai.com ，注册或登录。
  2. 充值：Settings → Billing → 充值（建议先充 10–30 美元）。
     再到 Limits 里设一个月度消费上限，例如 30 美元，这样最安全。
     注意：ChatGPT Plus 会员不包含 API 额度，API 要单独充值。
  3. 组织验证：gpt-image-1 这个画图模型要求先验证组织。
     Settings → Organization → General → Verify Organization，按提示完成（几分钟到几小时生效）。
     没验证的话，Claude 会告诉你"需要组织验证"。
  4. 创建 Key：API keys → Create new secret key → 复制 sk- 开头的那一长串。
     它只显示一次，先粘贴到记事本里。
  5. 在中国大陆需要代理或中转服务才能连上 OpenAI，见文末"常见问题"。
  费用：全套 88 项、算上重画，大约 18–35 美元。每次生成前 Claude 都会先报价，你同意了才开始。

B. 自己生成
  按《美术资产清单与提示词.txt》生成图片，然后打包成 美术资产包.zip：
  - 全部图片放进一个英文名的文件夹（例如 art_pack），再压缩成 zip。
  - 文件夹里加一个 credits.txt，写一行：你用的工具或模型，以及授权（记事本另存为时编码选 UTF-8）。
  - 文件名用清单里的英文名。Windows 请先在资源管理器里勾选「查看 → 显示 → 文件扩展名」再改名。
  可以先只做定调批或 P1，剩下的以后再补，缺的图游戏会用占位图代替。


第二步：安装 Godot 4.7.2（选"标准版"，不要选 .NET 版）
---------------------------------------------------
下载地址：https://godotengine.org/download

- Windows：
  解压到 C:\Godot\，里面有两个 exe，命令行要用带 _console 的那个。
  打开 PowerShell（按 Win 键，输入 PowerShell，回车），执行一次下面这句（执行后要重开终端才生效）：
      setx GODOT_PATH "C:\Godot\Godot_v4.7.2-stable_win64_console.exe"
  （文件名以你实际解压出来的为准）
- macOS：
  brew install --cask godot，或者下载 dmg 拖进"应用程序"。
- Linux：
  解压后 chmod +x，再把 GODOT_PATH 设为它的完整路径。


第三步：安装 Claude Code（Claude 必须在你自己的电脑上运行，才能驱动 Godot）
----------------------------------------------------------------------
- 最简单的方式：下载 Claude 桌面版 App，使用里面的 "Code"（代码）功能。
- 或者用终端安装：
      Windows PowerShell： irm https://claude.ai/install.ps1 | iex
      macOS / Linux：      curl -fsSL https://claude.ai/install.sh | bash
- Windows 还要装 Git for Windows：https://git-scm.com/downloads/win
  skill 里的脚本要靠它自带的 Git Bash 才能运行。
- 需要 Pro、Max、Team 或 Enterprise 账号。


第四步：安装 skill
------------------
Windows（最不容易出错的做法）：
  1. 打开 PowerShell（按 Win 键，输入 PowerShell，回车），执行：
         mkdir $env:USERPROFILE\.claude\skills
     如果提示"已存在"，没关系。
  2. 打开资源管理器，在地址栏输入 %USERPROFILE%\.claude\skills 后回车，打开这个文件夹。
  3. 双击 chimera-godot-gamedev.zip（不用解压），能看到里面有一个 chimera-godot-gamedev 文件夹。
     把这个文件夹直接拖进第 2 步打开的 skills 窗口。
  4. 检查：最终路径必须是 C:\Users\你的用户名\.claude\skills\chimera-godot-gamedev\SKILL.md。
     如果中间多了一层同名文件夹，Claude 会找不到 skill，要把里面那层拖出来，放到 skills 下面。

macOS / Linux：
  解压 zip 后，把 chimera-godot-gamedev 文件夹放到 ~/.claude/skills/ 下面，
  最终路径是 ~/.claude/skills/chimera-godot-gamedev/SKILL.md。

（可选）在 claude.ai 网页版里也想用：到设置里的 Skills 页面上传 chimera-godot-gamedev.zip。
不过网页聊天没法运行你电脑上的 Godot，做游戏一定要用 Claude Code。


第五步：新建工作区文件夹
------------------------
新建一个空文件夹，例如 D:\games\奇美拉工作区（名字随意，中文也可以）。
  - GPT 模式：在里面新建一个文本文件，名字叫 GPTapi.txt，打开后只粘贴一行 Key，保存。
    （Windows：在文件夹空白处右键 → 新建 → 文本文档 → 改名为 GPTapi.txt → 双击打开 → 粘贴 → 保存）
  - 自己出图：把 美术资产包.zip 放进去。
  - 两样都放也可以：Claude 会先导入你的资产包，缺的再用 GPT 生成。
其他什么都不用放。这两个 txt 和 skill 压缩包放进去也没关系，Claude 会自动忽略它们。

Claude 会在这个文件夹里自动建好两个子文件夹：
  美术资产\   美术车间：生成的候选图、等你复审的图、已通过的图、审核页面都在这里
  游戏\       Godot 游戏项目（以后开源发布的就是这个文件夹）

关于 Key 的安全：
  - GPTapi.txt 在游戏文件夹外面，不会进 git，也不会被上传。
  - Claude 被设置为不能打开这个文件，Key 只会被生图工具读取、发给 OpenAI。
  - 不要把整个工作区打包发给别人，也不要把 Key 直接贴进聊天里。


第六步：在工作区里启动 Claude Code
----------------------------------
- 桌面版：打开 Code，选择这个工作区文件夹。
- 终端：先 cd 到这个文件夹，再输入 claude。
Claude 运行脚本时会请求权限，选"允许，以后不再询问"会省事很多。
（可选）想让 git 提交记录里显示你的名字，在第七步之前，在 PowerShell 执行一次：
    git config --global user.name "你的名字"
    git config --global user.email "你的邮箱"
不设置也能正常开发：项目会自动用默认身份"Chimera Dev"提交。
如果项目已经建好了才想改，就在 游戏 文件夹里（不带 --global）再执行一次这两句。


第七步：发送一句话提示词（复制下面这一整行）
------------------------------------------

/chimera-godot-gamedev 请在当前文件夹从零开始做《奇美拉纪元》：建好工作区和游戏项目；美术用 GPT 生成（Key 在 GPTapi.txt；没有 Key 就用我放的资产包），你先初审，挑好的再给我复审，每批生成前先告诉我费用；然后按路线图一个里程碑一个里程碑开发，每完成一个里程碑用中文汇报并附截图，需要我拍板的事再问我。

（如果输入 / 之后没有弹出这个 skill，就把开头改成："使用 chimera-godot-gamedev 这个 skill，……"）

Claude 接下来会自动做这些事：
  找到 Godot → 建好 美术资产 和 游戏 两个文件夹 → 建项目、跑完整检查和测试、截图
  → 免费检查 Key 能不能用 → 告诉你"定调批"7 项的费用（大约 1.2 美元，含一个反派）→ 你回复"可以"
  → 生成候选图 → 它自己先初审（不合格的自动重画，每张最多 3 轮）
  → 把挑好的图装进游戏截图 → 在浏览器里打开审核页面，请你复审
  → 你复审期间，它直接开始开发第一个里程碑（可操作的战斗）。


复审怎么做
----------
1. 浏览器会自动打开「美术复审」页面（没打开的话，双击 美术资产\审核页面.html）。
2. 每张资产只给你看 Claude 推荐的图，旁边有：它的推荐理由、去背景后的效果、装进游戏的截图。
   有两张候选时，可以选"用推荐"或"用备选"。
3. 点「通过」或「不要」。不要的话写一句原因，例如"太写实""头太小""颜色太花"（也可以点下面的快捷标签）。
4. 最后点「提交复审结果」，然后回到 Claude。它会自动继续：
   通过的导入游戏；不要的按你的意见改提示词、重新生成，再给你复审，直到全部通过。
   如果页面提示"已下载 复审结果.json"，把这个文件放进 美术资产 文件夹，再跟 Claude 说"复审好了"。

定调批（7 项）通过后，画风就定下来了，后面的图会自动参考它们，整套美术风格统一（反派只参考反派）。
之后按 P1（42 项）→ P2（42 项）→ P3（4 项）的顺序继续，每一批都会先报价。

为什么复审是在网页里，不是在 Claude 对话里？
  审核页面是你电脑上的本地网页（地址是 127.0.0.1，只在你自己电脑上，不上网）。
  用网页是因为它能把图放大、并排对比、显示装进游戏的截图，点一下就把结果交回给 Claude，比在聊天里看图方便得多。
  不想开网页也行：跟 Claude 说"直接在聊天里给我看"，它会把推荐图逐张显示出来，
  你回复"1 通过，2 不要：太写实，3 用备选"这样就可以。


之后每次继续（换新会话也一样）
------------------------------
/chimera-godot-gamedev 继续开发：先读进度，美术有待处理的先处理（复审结果、待同步的图），然后从"下一步"接着做，做完当前里程碑再向我汇报。

进度都记在 游戏\docs\PROGRESS.md 和 美术资产\记录.json 里，不会丢。会话中途被打断时，直接说"继续"就行。


美术常用指令（按需复制）
------------------------
· /chimera-godot-gamedev 继续生成美术：P1 剩下的全部，总预算 10 美元以内不用再问我。
· /chimera-godot-gamedev 这张人物看起来太小了 / 不够好看 / 反派不够凶，按我的意思重画：＿＿。
· 复审好了。（页面提交后 Claude 没有自动继续时说这句）
· /chimera-godot-gamedev 这张 part_xxx 我不满意：＿＿，帮我重新生成。
· /chimera-godot-gamedev 现在美术进度怎么样？一共花了多少钱？还缺哪些？
· /chimera-godot-gamedev 暂停生成美术，先专心开发。
· /chimera-godot-gamedev 我想换一种美术风格：＿＿。请改风格锁定，先重做定调批给我看。
· 自己补图：把新的 zip 放进工作区，或者把图片放进 美术资产\已通过\（文件名用资产 id），
  然后说：/chimera-godot-gamedev 导入美术，截图检查效果，告诉我哪些要重做、还缺哪些。


常用开发指令（按需复制）
------------------------
· 跑一遍平衡模拟，把不达标的数值调回目标区间，然后告诉我改了什么、为什么改。
· 截一张现在的战斗画面给我看，并按视觉验收清单自己检查一遍。
· 我想加一个新种族「＿＿」，主题是＿＿。请按扩展清单把它加进去，同步美术清单，并做平衡。
· 我想加一个 Boss，它的核心机制是＿＿，要让玩家学会＿＿。
· 我玩下来觉得＿＿不好玩，请分析原因，给出 2–3 个改法，等我选。
· 准备开源发布：补齐 README、CONTRIBUTING、CHANGELOG，并检查素材授权。先不要推送，等我确认。


常见问题
--------
· 在中国大陆连不上 OpenAI：
  方法一：开代理软件，在 GPTapi.txt 第二行加：proxy=http://127.0.0.1:7890
          （7890 换成你代理软件里显示的"HTTP 代理端口"）。
  方法二：用 OpenAI 兼容的中转服务：第一行写中转给你的 Key，第二行写 base_url=中转地址。
  改完跟 Claude 说"再检查一下 Key"。
· 报"需要组织验证"：见第一步 A 的第 3 条，验证生效后再试。
· 报"余额不足"：到 OpenAI 后台 Billing 充值。
· 钱会不会乱花：
  每次生成前都会先报价；单次默认最多 3 美元（在 GPTapi.txt 加一行 budget=10 可以改）；
  你说了总预算，Claude 会让工具记着累计花费，超出就停下来问你（也可以在 GPTapi.txt 加一行 budget_total=20）；
  每张图最多自动生成 3 轮；网络超时的请求不会自动重试（免得重复扣钱）；
  再加上你在 OpenAI 后台设的月度上限，多重保险。
· Claude 说找不到 Godot：
  检查 GODOT_PATH 是否设置正确（Windows 要指向 _console.exe），然后重启终端或 Claude。
· 想自己玩玩看：
  双击 C:\Godot 里不带 console 的那个 Godot exe → 在项目管理器里点「导入」
  → 选工作区里 游戏 文件夹中的 project.godot → 打开后按 F5。
  演示场景的按键：D 演示组　R 随机敌族　F 随机融合　B 重跑战斗。
· 导入后部件位置歪了：
  直接告诉 Claude"xxx 的位置不对"，它会调对齐参数并重新截图，不用重画。
· 开源吗：
  Godot 引擎是 MIT 协议，免费、不抽成。项目默认代码用 MIT，美术用 CC BY-SA 4.0。
  GPT 生成的图会在 CREDITS.md 里注明"OpenAI 生成"。发布前请确认 OpenAI 当前的使用条款。
  Claude 只在本地提交，推送到 GitHub、发布到 itch.io 之前都会先问你。
